У каждого ответа поля id, status, answer, quote, file. status: «ответ», «расхождение»,
«нет в документах» или «не знаю». answer — ответ; quote — дословная цитата минимум
8 символов; file — имя файла. Для отсутствующих сведений и неопределённости
оставь answer, quote, file пустыми. Числа пиши цифрами. Включи каждый ID один раз.
