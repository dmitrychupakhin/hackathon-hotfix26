# Предпросмотр документов и ссылки на цитаты

## Контракт для frontend и backend

В истории Django `GET /api/chats/{chat_id}/messages` у ответа ассистента сохраняются:

- `content`: текст ответа или уточняющий вопрос;
- `answer_payload`: полный AI Answer, включая статус, evidence, checks и calculation;
- `citations`: подготовленные backend ссылки на проверенные фрагменты.

Для нескольких вопросов `answer_payload.parts` хранит независимые результаты с текстом вопроса, статусом, проверками и `citation_ids`, ссылающимися на верхний `citations[].id`. Ссылки показываются под своим пунктом; один неопределённый пункт не скрывает подтверждённые ответы. Верхний `partial` — наличие неопределённых пунктов. Подробности: [контракт Django-чата](../../backend/chats/README.md#несколько-вопросов-в-одном-сообщении).

Панель документа располагается справа. Заголовок находится вне прокручиваемой области; прокручивается только полный документ. Переход к цитате выравнивает её по верхней границе области, чтобы не оставлять сверху хвост предыдущей страницы. PDF остаётся постраничным оригиналом (включая его поля); DOCX — безопасное представление полного содержимого, TXT/MD — полный исходный текст. Редактирование и копирование ссылки на положение отсутствуют.

Поля `answer_payload` и `citations` доступны только для чтения. Старые сообщения, созданные до миграции `chats.0005_message_evidence`, имеют пустые объекты/списки: восстановление старых доказательств автоматически не выполняется.

Пример citation (числа условные):

```json
{
  "id": "<file-id>:<text-sha256>:120:138",
  "file_id": "<file-id>",
  "file_name": "contract.pdf",
  "quote": "Точная цитата ...",
  "start": 120,
  "end": 138,
  "text_sha256": "<SHA-256 canonical UTF-8 text>",
  "version": "<source version>",
  "locations": [{"page": 2, "start": 100, "end": 500}],
  "preview_url": "/api/chats/<chat-id>/files/<file-id>/preview?text_sha256=...&version=...",
  "offset_unit": "unicode_code_points",
  "anchor_method": "harness_evidence"
}
```

`start/end` относятся к **каноническому извлечённому тексту**, который возвращает preview. `end` не включается. Это Unicode code points (Python), а не индексы UTF-16 JavaScript: для среза используйте `Array.from(text).slice(start, end).join('')`. Перед подсветкой проверьте совпадение с `quote`. Не ищите первый совпавший текст, если координаты или хеш не совпали: одинаковая фраза может встречаться несколько раз.

`locations` описывает страницы PDF, листы XLSX или слайды PPTX и их диапазоны в извлечённом тексте. Это **не геометрические координаты** на PDF. Для PDF можно открыть исходную страницу и отдельно подсветить точный текстовый фрагмент. После уточнения цитаты AI оставляет только пересекающиеся locations.

## HTTP

Все Django маршруты требуют обычную авторизацию и проверяют владельца чата и файла. Ссылка не содержит токена доступа.

- `GET /api/chats/{chat_id}/files/{file_id}/preview`: `{file_id,name,format,text,text_sha256,original_sha256,version,locations,partial,warnings,offset_unit,content_url}`.
- `GET /api/chats/{chat_id}/files/{file_id}/content`: исходные байты PDF/DOCX с `Content-Disposition: inline`; для остальных форматов канонический UTF-8 TXT. Заголовки `Cache-Control: private, no-store`, `X-Content-Type-Options: nosniff`.
- Оба маршрута принимают `text_sha256` и `version`. Несовпадение возвращает `409`, переход к устаревшей цитате нужно остановить. При получении оригинала передавайте хеш и версию из preview/цитаты тоже.

`format` сохраняет PDF, DOCX, TXT, MD. Все другие поддерживаемые извлекателем форматы возвращают `format=txt`. Само расширение не расширяет список поддерживаемых парсером файлов. Пустой извлечённый текст, `partial` и `warnings` должны быть видны пользователю. Валидный скан PDF можно открыть в оригинале без OCR, но preview возвращает пустой текст, `partial=true` и предупреждение `ocr_required`/`ocr_unavailable`/`ocr_empty_text`; чтение такого источника моделью и точные текстовые ссылки требуют работающего OCR. Повреждённые, защищённые или превышающие лимиты файлы по-прежнему возвращают ошибку.

Для оригинала используйте авторизованный fetch → Blob → object URL. Не размещайте JWT в query string и не вставляйте серверные пути. PDF/DOCX нельзя считать соответствующими цитате, если загрузка с ожидаемой версией вернула 409.

AI предоставляет внутренний `GET /api/v1/files/{file_id}/preview` с сервисным ключом и `X-User-ID`. Он получает файл только из owner-scoped PostgreSQL `ai.files`, использует существующий безопасный кеш извлечения и не раскрывает локальные пути. Платных запросов к модели при preview нет. Разбор ограничен существующим таймаутом импорта (по умолчанию 300 секунд); отдельный парсер — 45 секунд.

## Доверенная идентичность источника

В AI Span теперь передаются `source_file_id`, `source_version`, `original_sha256`, а `source_hash` остаётся хешем извлечённого текста. Эти поля заполняет код из зафиксированных источников, не модель. Django сопоставляет только существующие файлы своего чата, проверяет исходный SHA-256/версию и длину фрагмента. URL строится самим Django. Имена файлов, произвольные пути и модельные URL не используются для определения источника. Повторяющиеся доказательства объединяются по ID файла, хешу и координатам.

Исходное имя файла сохраняется для отображения. Если два документа имеют одинаковые имена, внутреннее имя пакета получает суффикс ID; `Span.file` и `citation.file_name` продолжают показывать исходное имя.

## Восстановление прогресса

`Chat.latest_run` возвращает `{id,status,error,created_at,updated_at}` или `null`. Это Django ID запуска. `GET /api/chats/{chat_id}/runs/{run_id}/events?after=0&limit=100` возвращает owner-scoped события AI, связывая ID на сервере. До отправки запроса в AI возвращается пустой список. `after >= 0`, `limit` от 1 до 500 (тот же предел, что у AI). Этот маршрут нужен для восстановления после перезагрузки и HTTP-резерва к WebSocket; события дедуплицируются по `seq`.

В `plain` уникальная дословная цитата в явно названном источнике может получить координаты с `anchor_method=exact_text_match`. Это только навигация: содержание ответа, его статус и пустой список проверок не меняются. Отсутствующая, неоднозначная или нормализованная моделью цитата ссылку не получает. Реальная цитата сама по себе не доказывает правильность сопровождающего ответа. В `baseline` и `raw` такая обработка не применяется.

Предупреждение `docx_page_layout_unavailable` означает отсутствие Word-пагинации, а не потерю текста: само по себе оно не делает прочитанные источники неполными для критика/проверки отсутствия ответа. `partial=true`, пустой текст, предупреждения об изображениях, OCR и любые неизвестные предупреждения сохраняют запрет считать покрытие полным.
