# Проверка реализации — 7 ноября 2026

## Выполнено

- Общий `pytest -q`: **107 passed**, 2.99 секунды. Модели и внешний backend заменены заглушками; платных вызовов в тестах нет. Есть предупреждение Starlette о будущем переходе тестового клиента с httpx на httpx2; ошибок нет.
- `ruff check app tests scripts`, `ruff format --check app tests scripts`: успешно.
- `uv lock --check --offline`: зависимости согласованы с pyproject.
- `scripts/export_openapi.py`: снимок HTTP-схемы обновлён.
- Отдельный Docker-образ `onsoft-ai:local` собран; временный контейнер успешно запущен и удалён после проверки.
- В контейнере проверены Swagger, OpenAPI, health, импорт всех **6 закупок / 26 документов / 71 вопроса**. Генерация ответов в этой проверке не запускалась. Без переданного ключа readiness возвращает 503 — ключ в образ не встроен.
- В образе проверены импорты парсеров и наличие OCR-языков `rus`, `eng`. Реальное качество OCR на сканах не измерялось; поведение OCR проверено моками.
- Ревью выявило и исправило пять дефектов: повторная отмена во время сохранения, потеря расчёта перед критиком, знаки чисел, Unicode-переносы CSV, история диалога в сравнении входов. Добавлены регрессионные тесты. Повторное ревью проходов длинных документов новых существенных ошибок не выявило.

## Реальный smoke-запрос

До добавления проходов больших документов выполнен небольшой синтетический запрос к `openai/gpt-6-luna`: нативный `submit_answers`, проверки кодом, отдельный смысловой критик. Успешно: **2 вызова, 23.554 секунды, 1733 входных + 175 выходных = 1908 токенов**. Журнал: `output/live-smoke.json` (локальный, исключён из Git).

Цены провайдера в настройках не заданы, поэтому стоимость в журнале `null`. Только при предположении единой цены пользователя 60 ₽ за миллион любых токенов это **0.11448 ₽**; это расчёт по условному тарифу, не подтверждение списания.

## Границы результата

107 тестов проверяют код и контракты, а не фактическую точность LLM. Новые проходы больших документов проверены заглушками, отдельный платный прогон этого пути не выполнялся. Весь новый harness ещё не оценён на 71 вопросе: нужны baseline/harness на одной модели и официальная оценка; команды находятся в README.

HTTP-загрузка сейчас TXT/MD. Модуль PDF/Office/OCR и клиент получения по ID существуют отдельно и проверены, но их подключение к FastAPI, настройкам и сохранению provenance отложено по просьбе пользователя. Django endpoint получения файла тоже ещё не реализован. Контракт: [backend-files.md](backend-files.md).

Глобальный Compose, backend и frontend не изменены. Корневой `.env` сохранён; уже существовавшее изменение `.env.example` не относится к этому сервису.
