# ContextMenu

Источник: Figma → Context menu (`3:1579`), панель Theme=Light (`3:1624`)
и 12 вариантов пунктов (`3:1590`). Исходный компонент добавлен через
`npx shadcn@latest add context-menu --yes`, затем адаптирован под проект.
Новых зависимостей не добавлено.

## Использование

Один публичный компонент принимает область открытия и список действий:

```tsx
"use client";

import { FolderIcon } from "@heroicons/react/24/outline";
import { ContextMenu } from "@/shared/ui/context-menu";

<ContextMenu
  items={[
    { id: "open", label: "Открыть", icon: <FolderIcon />, onSelect: openFolder },
    { id: "delete", label: "Удалить", variant: "destructive", onSelect: deleteFolder },
  ]}
>
  <div>Область контекстного меню</div>
</ContextMenu>
```

Функции действий передаются из Client Component. Дочерний элемент становится
триггером через Base UI `render`, без дополнительной обёртки. По умолчанию
доступен с клавиатуры через tabIndex=0. Меню открывается правой кнопкой мыши,
длительным касанием или нативным клавиатурным вызовом контекстного меню.

## API

- `items` — массив пунктов со стабильными уникальными `id` и строковыми `label`.
- `icon` и `iconPosition`: `left` (по умолчанию) или `right`. Иконки декоративные.
- `variant`: `default` или `destructive` (вариант Default warn в Figma).
- `active` — управляемый визуальный маркер Active. Нажатие также показывает
  Active; компонент не сохраняет выбор действия самостоятельно.
- `disabled` — блокирует активацию пункта.
- `onSelect` — обработчик действия с событием Base UI Item. После обычного
  выбора Base UI закрывает меню.
- `label` — доступное название меню, по умолчанию «Контекстное меню».
- `className` — класс панели, например для изменения ширины.
- `open`, `defaultOpen`, `onOpenChange` и остальные props Base UI Root поддерживаются.
- `triggerMode="click"` открывает меню нажатием на кнопку или с клавиатуры и
  располагает его под триггером; по умолчанию используется контекстное меню.

Позиционирование у указателя, portal, коллизии с краями окна, клавиатурная
навигация, typeahead и закрытие остаются ответственностью Base UI 1.9.
В Base UI disabled-пункты доступны для фокуса стрелками, но не активируются.

## Дизайн

Панель: белый фон Content/0, радиус 16px, padding 6px, gap между пунктами 0,
минимальная ширина 153px. Ширина растёт под содержимое и ограничена доступной
областью окна. Внутренняя рамка 1px чёрного с альфой 8%.

Тени из Figma: offset 0/4px, blur radius 12px, цвет #0a0a0a0a;
offset 0/12px, blur radius 32px, цвет #0a0a0a14. Figma blur преобразован в CSS
с коэффициентом 0.85: 10.2px и 27.2px. Параметры панели вынесены в общие токены
`globals.css`: `--shadow-context-menu`, `--color-context-menu-border`,
`--container-context-menu`.

Пункт: высота 40px, padding 8px / 12px, иконка 24px с gap 12px,
типографика Body/base/regular (16/24px, Golos Text 400).

| Состояние | Фон | Радиус | Текст и иконка |
| --- | --- | --- | --- |
| Default | Прозрачный | 12px | Special/100 |
| Default warn | Прозрачный | 12px | Error/600 |
| Hover / клавиатурная подсветка | Special/200 | 10px | Цвет варианта |
| Active | Accent/200 | 10px | Цвет варианта |

Цвета меняются через общий `transition-interaction` с reduced-motion.
Анимаций появления в Figma нет, дополнительные движения не добавлены.
В выделенном наборе нет подменю, разделителей и пунктов с checkbox/radio —
их оформление не придумано. Disabled дополнительно поддержан с opacity 50%.

На странице компонентов есть `ContextMenuExample`: действия только показывают
выбранную подпись и не изменяют данные приложения.

## Проверка

TypeScript, Biome и компиляция всех классов Tailwind проходят. Параметры
пунктов сверены со всеми 12 вариантами. DOM-проверка подтвердила открытие правой
кнопкой, portal, расположение иконок, warning, disabled, навигацию стрелками,
выбор пункта и закрытие через Escape. Визуальная проверка в настоящем браузере
пока недоступна: сервис управления браузером не подключён.
