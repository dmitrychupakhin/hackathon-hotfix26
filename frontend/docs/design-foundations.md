# Основы дизайна

Источник: свойства компонентов и Auto Layout в Figma, страницы Design-app,
Buttons и Inputs. Правила приняты для фронтенда; согласование с дизайнером ожидается.
Конфигурация Tailwind v4 находится в `src/app/globals.css`.

## Типографика

44 Text styles из Figma сведены к 11 размерам с парными line-height и четырём
весам Golos Text. Использование и исключение H1/bold описаны в `docs/typography.md`.
Размеры задаются классами `text-h1`–`text-h6`, `text-body-*`, `text-label-*`;
стандартная шкала размеров Tailwind заменена проектной.

## Радиусы

Значения независимы и не вычисляются от одного базового радиуса.

| Класс | Значение | Применение |
| --- | --- | --- |
| `rounded-sm` | 10px | Маленькие кнопки, обёртки иконок меню |
| `rounded-md` | 12px | Средние кнопки, поля ввода |
| `rounded-lg` | 14px | Большие кнопки |
| `rounded-xl` | 16px | Пункты навигации |
| `rounded-2xl` | 20px | Карточки профиля и лендинга |
| `rounded-3xl` | 24px | Формы авторизации, FAQ |
| `rounded-4xl` | 32px | Крупные поверхности, футер |
| `rounded-full` | Полное скругление | Круглые элементы |

`rounded-none` сохраняется для прямых углов. Стандартная именованная шкала
Tailwind сброшена; используются перечисленные значения. `rounded-full` —
встроенная утилита Tailwind, она не требует переменной темы.
При реализации компонента радиус закрепляется внутри его варианта/размера.
Уточнение после чтения всех вариантов кнопки: маленькая Primary с текстом
имеет 10px, маленькая Secondary и кнопки только с иконкой — 12px.
Подробности — в `docs/button.md`.

## Отступы

Базовый шаг `--spacing: 0.25rem` — 4px при корневом размере шрифта 16px.
Половинные шаги дают 2px. Повторяющиеся значения 10, 12, 14, 16, 20, 24,
32 и 44px сохраняются; принудительного округления до 8px нет.

| Элемент | Padding: вертикальный / горизонтальный | Gap |
| --- | --- | --- |
| Маленькая кнопка | 10 / 16px | 12px |
| Средняя кнопка | 12 / 24px | 12px |
| Большая кнопка | 16 / 32px | 12px |
| Поле ввода | 12 / 16px | 12px до иконки |
| Форма авторизации | 32 / 32px | 32px между блоками, 16px между полями |
| Карточка профиля | 32 / 44px | 24px |
| Карточка лендинга | 20 / 24px | 12px |
| FAQ | 24 / 24px | 16px между карточками |
| Крупный блок лендинга | 64 / 44px | 32px |

Примеры: `gap-3` = 12px, `p-6` = 24px, `px-11` = 44px.
Правила компонентов описаны здесь для будущей реализации; сами компоненты
этим изменением не создаются.

## Исключения и адаптивность

- Интервалы 1–2px внутри текста остаются локальными деталями компонента.
- Единичные 33 и 62px — кандидаты на 32 и 64px. Нормализация выполняется
  при реализации конкретного блока с визуальной проверкой, не автоматически.
- Интервалы 130, 389, 512px не становятся глобальными токенами.
  Учитываются режим Auto Layout, распределение свободного пространства и адаптивность.
- Радиусы оболочек COMPONENT_SET и детали векторных иконок не входят в шкалу UI.

## Переходы состояний

Общие токены в `src/app/globals.css`:

- `--motion-duration-interaction: 300ms` — длительность.
- `--ease-interaction: ease` — кривая, как у кнопок Beady.

Класс `transition-interaction` плавно меняет цвет текста, фон, цвет границ,
цвет outline и box-shadow (включая внутреннюю обводку). Его можно использовать
у кнопок, полей и других интерактивных элементов. Класс задаёт переход,
а цвета конкретных состояний остаются ответственностью компонента.

```tsx
<div className="transition-interaction bg-content-0 hover:bg-content-50">
  Содержимое
</div>
```

При `prefers-reduced-motion: reduce` переход отключается внутри самого класса.
Размеры, положение и масштаб не анимируются. Новые библиотеки не требуются.
