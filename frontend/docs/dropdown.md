# Dropdown

Поле выбора с поиском и одним или несколькими значениями. При фокусе открывается список, ввод фильтрует варианты без учёта регистра. Подходящая часть текста подсвечивается. Если совпадений нет, отображается сообщение.

```tsx
<Dropdown options={options} label="Город" placeholder="Выберите город" />

<Dropdown
  multiple
  options={options}
  label="Города"
  placeholder="Выберите города"
  defaultValue={["moscow"]}
  onValueChange={(values) => console.log(values)}
/>
```

`options` — массив объектов `{ value, label, disabled? }`. В одиночном режиме значение — строка или `null`, в множественном — массив строк. Для управляемого состояния используйте `value` и `onValueChange`. Выбранные значения в множественном режиме можно удалять по отдельности; поле переносит их на новые строки и остаётся доступным для ввода. Поддерживаются клавиатура, `disabled`, `readOnly`, `name`, `form` и `required`. Через `emptyText` можно изменить сообщение об отсутствии результатов, через `onSearchChange` — отслеживать поисковый запрос.

Список и состояния вариантов перенесены из Figma. Вариант меток выбранных значений в поле в макете отсутствует: для него использованы существующие цвета, типографика и скругления проекта.
